# Портфолио

Персональный сайт frontend-разработчика и веб-дизайнера. Здесь собраны основные и дополнительные проекты, описание моего вклада, используемые технологии и информация об опыте.

Сайт поддерживает русский и английский языки, адаптирован под мобильные устройства и позволяет управлять всеми кейсами через единый типизированный каталог.

## Возможности

- основные и дополнительные проекты;
- подробные модальные окна с галереями;
- русская и английская локализация;
- сохранение выбранного языка в `localStorage`;
- адаптивная версия для компьютеров, планшетов и телефонов;
- автоматическое подключение обложек и изображений проектов;
- клавиатурная навигация, управление фокусом и поддержка `prefers-reduced-motion`;
- автоматическая нумерация проектов по заданному порядку.

## Технологии

- React 19;
- TypeScript;
- Vite;
- SCSS Modules;
- Lucide React;
- ESLint и Prettier.

## Запуск проекта

```bash
npm install
npm run dev
```

После запуска Vite выведет адрес локального сервера в терминале.

Production-сборка:

```bash
npm run build
npm run preview
```

## Каталог проектов

Все кейсы описываются в [`src/data/projects/catalog.ts`](src/data/projects/catalog.ts). Технические параметры проекта задаются один раз, а русская и английская версии текста хранятся рядом в `content`.

Поле `placement` определяет расположение:

- `featured` — основной список;
- `additional` — блок «Другие проекты».

Поле `order` отвечает за сортировку. Отображаемые номера `01`, `02`, `03` и далее вычисляются автоматически, поэтому вручную поддерживать их не нужно.

Пример записи:

```ts
{
  id: 'project-name',
  placement: 'featured',
  order: 100,
  accent: '#123456',
  layout: 'editorial',
  content: {
    ru: {
      title: 'Название проекта',
      description: 'Краткое описание проекта.',
      contribution: 'Краткое описание моего вклада.',
      contributionPoints: ['Первый результат', 'Второй результат'],
      role: 'Frontend Developer',
      projectTypes: ['Коммерческий проект'],
      technologies: ['React', 'TypeScript'],
    },
    en: {
      title: 'Project name',
      description: 'Short project description.',
      contribution: 'Short contribution description.',
      contributionPoints: ['First result', 'Second result'],
      role: 'Frontend Developer',
      projectTypes: ['Commercial project'],
      technologies: ['React', 'TypeScript'],
    },
  },
}
```

Дополнительно можно использовать:

- `private: true` — пометка кейса без конфиденциальных данных;
- `note` внутри локализованного контента — блок «Важно»;
- `layout: 'dashboard' | 'editorial' | 'mobile'` — вариант отображения обложки.

Каталог проверяет уникальность `id` и `order`, формат `kebab-case` и наличие обязательной обложки.

## Добавление нового проекта

### 1. Подготовить изображения

Создайте папку, имя которой совпадает с `id` проекта:

```text
src/assets/projects/project-name/
├── cover.webp
├── gallery-01.webp
├── gallery-02.webp
└── gallery-03.webp
```

Правила именования:

- `cover` — обязательная обложка;
- `gallery-01`, `gallery-02` и далее — изображения для модального окна;
- поддерживаются `avif`, `jpeg`, `jpg`, `png` и `webp`;
- для корректной сортировки используйте двузначные номера;
- название папки и `id` должны быть записаны в `kebab-case`.

Все изображения подключаются автоматически через `import.meta.glob`. При добавлении нового экрана в существующую галерею менять импорты или компоненты не нужно.

### 2. Добавить запись в каталог

Добавьте один объект в `projectCatalog`, заполните обе языковые версии и выберите `featured` либо `additional`.

Для `order` используется шаг `10`. Это позволяет вставлять новые проекты между существующими без массового изменения значений.

## Локализация

Интерфейсные переводы находятся в [`LanguageProvider.tsx`](src/providers/LanguageProvider/LanguageProvider.tsx). Данные секций «Обо мне» и «Экспертиза» находятся в [`site-content.ts`](src/data/site-content.ts), а тексты проектов — непосредственно в каталоге.

При переключении языка обновляются интерфейс, метаданные страницы и содержимое открытого кейса.

## Проверка перед публикацией

```bash
npm run typecheck
npm run lint

```

Собранный сайт будет находиться в директории `dist` и может быть размещён на любом статическом хостинге.
