# Project catalog

Все проекты описываются в `catalog.ts`. Одна запись содержит техническую конфигурацию и оба языка, поэтому основные и дополнительные проекты используют одну модель данных.

## Медиа

```text
src/assets/projects/
└── project-id/
    ├── cover.webp
    ├── gallery-01.webp
    ├── gallery-02.webp
    └── gallery-03.webp
```

- Имя папки должно совпадать с `id` проекта.
- Обложка обязательна при использовании `getProjectMedia`.
- Поддерживаются `avif`, `jpeg`, `jpg`, `png` и `webp`.
- Галерея сортируется по имени, поэтому используйте двузначные номера.
- Имена вроде `case9_1` не используются: slug и назначение файла должны быть понятны без обращения к коду.

## Размещение и порядок

`placement` определяет секцию:

- `featured` — основной список;
- `additional` — «Другие проекты».

`order` определяет общий порядок. Рекомендуемый шаг — 10, чтобы между существующими проектами можно было вставить новый. Номера `01`, `02` и далее формируются автоматически после сортировки.
